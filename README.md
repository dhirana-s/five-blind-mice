# SilverLine AI – Multi-Agent Emergency Triage Copilot

AI triage assistant for Personal Alert Button (PAB) distress cases. SilverLine AI helps operators quickly understand emergency alerts by analyzing audio distress signals, transcripts, and patient context using a multi-agent reasoning pipeline. The system assists operators by generating:
- emergency triage classification
- primary medical concern
- critical follow-up questions
- recommended response actions

This reduces response time and improves decision quality in emergency situations.


### System Overview

SilverLine AI is built as a multi-agent triage architecture combining:
- React operator dashboard
- FastAPI AI backend
- OpenAI multimodal models
- MERaLiON dialect model
- Supabase data infrastructure

The system processes audio distress alerts and produces structured triage recommendations.
